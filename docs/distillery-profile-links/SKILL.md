To find the links for a distillery, do the following:

- Website: Google search query "{name} distillery virginia website"
- Instagram: Google search query "{name} distillery virginia instagram"
- Facebook: Google search query "{name} distillery virginia facebook"

For example, to find the links for Open Road, do the following:

- Website: Google search query "Open Road distillery virginia website"
- Instagram: Google search query "Open Road distillery virginia instagram"
- Facebook: Google search query "Open Road distillery virginia facebook"

The results will be a list of websites, Instagram profiles, and Facebook pages. Generally one of the first links on the page will clearly be the official website or social media.
## How to Find Official Distillery Links

For each distillery, locate their primary website and official social profiles using the following process:

1. **Website**:
   Google search:
   > {distillery name} distillery virginia official website
   Example:
   > Open Road distillery virginia official website

2. **Instagram**:
   Google search:
   > {distillery name} distillery virginia instagram
   Example:
   > Open Road distillery virginia instagram

3. **Facebook**:
   Google search:
   > {distillery name} distillery virginia facebook
   Example:
   > Open Road distillery virginia facebook

### Step-by-Step Instructions

- Use Google rather than relying on direct string guessing (names may vary).
- Prefer results where the title or summary matches the distillery’s branding or location.
- For social media, prefer pages/profiles with consistent branding and follower counts typical for a business.
- If there are multiple possible links, choose the one that is most recently updated or referenced on their website.

### Output Format

When extracting links, provide all discovered URLs as fields:

```
{
  "distillery": "Open Road",
  "website": "https://openroaddistillery.com/",
  "instagram": "https://instagram.com/openroaddistillery",
  "facebook": "https://facebook.com/openroaddistillery"
}
```

If a link does not exist or cannot be confidently identified, use `null`.

### Usage Notes

- Many Virginia distilleries are small—verify that the link is not to a namesake in another state.
- Some may lack Instagram or Facebook; that's normal.
- Official links help power profile pages and clickable bracket links.

This skill ensures that all distillery profile links are sourced systematically and consistently for inclusion in the bracket website and related tools.
